Course Synthesis Project Report

1. Subject Connection & Role Architecture

Subject Topic Used Implementation in Project
FLAT Regular Expressions & DFA (Unit 1.5, 2.7) The Lexer validates assembly strings character-by-character using a state transition function δ(q, c), trapping invalid register identifiers or malformed syntax into q_reject.
COA 5-Stage Pipelining & RAW Hazards (Unit 3.1, 3.7) The Pipeline Engine models IF, ID, EX, MEM, and WB latches. It detects Read-After-Write data hazards and inserts precise stall cycles, with a toggleable Hardware Forwarding Unit.
DAA DAGs & Topological Sorting (Unit 1.11, Kahn's Algorithm) The Instruction Optimizer models true data dependencies as a Directed Acyclic Graph. Kahn's algorithm reorders independent instructions to fill RAW latency slots, maximizing pipeline throughput.

2. Theoretical Analysis & Latency Model

In a standard 5-stage MIPS pipeline without forwarding, an ALU instruction produces its result in the EX stage (Cycle 3) and writes back to the register file in the first half of the WB stage (Cycle 5). A dependent instruction reading that register in ID must stall for 2 clock cycles.

When the DAA optimizer applies Kahn's algorithm, it identifies instructions with in-degree 0 that do not read registers modified by recent instructions, inserting them into the bubble slots. This reduces pipeline duration from 12 cycles to 11 cycles (or more on larger basic blocks) with zero semantic deviation.
